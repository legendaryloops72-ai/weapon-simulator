# Weapon Simulator / محاكي الأسلحة

مشروع Android أصلي جديد مبني بـ Kotlin وJetpack Compose وMaterial 3، مستوحى من الحزمة المرجعية المرفقة. اسم التطبيق الظاهر للمستخدم: **محاكي الأسلحة**.

## الحالة الحالية

هذه أول نقطة تأسيسية للمستودع الجديد وليست ادعاءً بأن التطبيق النهائي مكتمل. تم تجهيز بنية Compose قابلة للتوسعة، الأقسام الرئيسية، شبكة العناصر، المفضلة داخل الجلسة، شاشة الإعدادات، وضع المؤثرات الآمن، وإدارة الضغط المستمر على العناصر. لم تتم إضافة صور العناصر النهائية أو التسجيلات الصوتية المرخصة بعد؛ راجع `SOUND_ASSETS_MANIFEST.md` و`TODO.md`.

## المتطلبات التقنية

- Kotlin 2.1.20
- Jetpack Compose + Material 3
- Android Gradle Plugin 8.9.2
- compileSdk / targetSdk 36
- minSdk 24
- دعم RTL مفعّل في Manifest

## التشغيل

افتح المشروع في Android Studio حديث يدعم AGP 8.9.x، ثم شغّل مهمة `assembleDebug`. يتطلب البناء SDK 36 وJDK 21. لا توجد مفاتيح سرية أو ملفات توقيع داخل المستودع.

## المراجع

الصور الأصلية محفوظة في `docs/reference_images/` للاستخدام كمرجع تصميمي فقط، وليست صور منتجات نهائية. تم تحليلها بصريًا على مستوى الاتجاه العام: خلفيات داكنة، توهجات حمراء/زرقاء/بنفسجية، بطاقات بإضاءة محيطية، وشبكات عناصر موجهة للهاتف.

## السلامة والخصوصية

صلاحية الكاميرا موجودة كصلاحية اختيارية للفلاش الخارجي فقط، ويجب طلبها وقت الاستخدام لا عند بدء التطبيق. يجب إيقاف أي مؤثر عند رفع الإصبع أو مغادرة الشاشة، مع إبقاء الوضع الآمن متاحًا لتقليل الوميض.
